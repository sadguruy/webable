# Changelog

This page tracks version-to-version changes in **Webable** so the component
library stays easier to maintain, review, and adopt across projects.

> Update this file whenever a component is added, changed, improved, or removed.

## Versioning notes

- Use a new section for each released version
- Group updates by `Added`, `Changed`, `Fixed`, and `Removed` when useful

## `0.1.3`

Component library expansion with new form controls, layouts, and utilities.

### Added

- `ActionLists` component for displaying action items with icons and descriptions
- `CheckboxGroup` component for multi-select checkbox functionality
- `Divider` component for visual content separation
- `Grid` component for responsive layout systems
- `Header` component for page and section headers
- `Icon` component for rendering SVG icons with sizing support
- `ImageUpload` component for handling image file uploads with preview
- `LoginModel` component for login/authentication dialogs
- `RadioGroup` component for single-select radio functionality
- `SelectField` component for dropdown selection inputs
- `Spacing` component for consistent margin and gap utilities
- `StatusAlert` component for status messages and notifications
- `Table` component for data table displays
- `TextareaBlock` component for multi-line text input areas
- `TextField` component for single-line text input fields
- `TextStyle` component for typography styling and text variations
- Storybook stories for all new components

## `0.0.1`

Initial foundation release for the Webable component library.

### Added

- Base library setup with Vite, TypeScript, and Storybook
- `ActionButton` component with reusable variants:
  `default`, `primary`, `secondary`, `warning`, `error`, and `danger`
- Support for button sizes: `small`, `medium`, and `large`
- Support for width modes: `auto` and `full`
- Optional left and right icon placement in `ActionButton`
- Storybook stories for interactive button states and variants
- Welcome documentation page for the library overview

### Changed

- Replaced the default Storybook starter button with a reusable library-ready
  `ActionButton`

### Fixed

- Cleaned up starter story files so the library build passes cleanly
